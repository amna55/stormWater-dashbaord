# Watershed & Storm Sewer WebGIS Dashboard
**Interactive drainage analysis visualization — Dallas, Texas**

🔗 **[View Live Dashboard](https://stormsewerdash.netlify.app/)**

---

## About

An interactive WebGIS dashboard built to visualize stormwater drainage analysis results for a commercial development project in Dallas, TX. Developed as part of a full drainage engineering study submitted to the City of Dallas.

The dashboard turns static engineering calculations into an interactive map that clients and reviewers can explore directly in a browser — no software required.

---

## Features

- Interactive map with toggleable layers
- Clickable storm drain inlets with hydraulic data
- Storm event switcher (2-yr, 10-yr, 50-yr, 100-yr)
- Pipe network visualization by material and system
- FEMA floodplain overlay
- Real GPS coordinates from field survey data

---

## Built With

`Leaflet.js` `OpenStreetMap` `HTML/CSS/JS` `HEC-HMS` `Rational Method` `Manning's Equation` `NOAA Atlas 14` `City of Dallas DDM (2019)`

---

## Part of a Larger Workflow

This dashboard is the visualization layer of a complete drainage engineering workflow including:

- Watershed delineation and hydrologic modeling (HEC-HMS)
- Pre and post development runoff analysis
- Storm sewer pipe sizing and slope calculations
- Technical report for city permit submission
